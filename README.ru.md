### 📖 О проекте

Тысячелетиями человек подчинял мир с помощью одного фундаментального правила:  
**если не можешь понять целое — раздели его на части.**

Этот принцип подарил нам науку, конвейерное производство, инженерное мышление и цифровую цивилизацию. Но что происходит, когда разрез доходит до своего технологического предела? Когда мы способны с абсолютной точностью измерить каждую деталь, миллисекунду и нейромедиатор, но перестаем видеть то, что возникает между ними?

**«Искусство разделять»** — интерактивное философско-научное эссе о границах редукционизма, эмерджентной сложности, квантовой нелокальности, биологических симбиозах и архитектуре связей.

> **Не нож. Мост.**

---

### 📑 Оглавление

1. **Первый разрез** — Как имя отделило явление от хаоса. Рождение инструмента анализа.
2. **Величайший успех** — Механическая картина мира, часы, конвейер и триумф декомпозиции.
3. **Слишком острый нож** — Парадокс предельного измерения: почему сумма частей беднее целого.
4. **Архитектура связей** — Почему отдельная молекула H₂O не влажная и где на самом деле рождается реальность.
5. **Иллюзия границ** — Нобелевская премия по физике 2022 года, человек как холобионт и механизм Self-Attention в нейросетях.
6. **Следующий подвиг** — Исчерпание чистого анализа и наступление эпохи Синтеза.

### ⚡ Архитектура и технологии

* **Чистый веб (Zero Dependencies):** Написан без тяжелых фреймворков и библиотек — только семантический HTML5, чистый CSS3 и нативный JavaScript.
* **Внимание к чтению:** Фокус на верстке текста, прогресс-бар чтения и удобное выдвижное оглавление.
* **Поисковая оптимизация и стандарты (SEO):**
  * Корректная многоязычность через взаимные теги `hreflang` и `canonical`.
  * Семантическая микроразметка `Schema.org/Article` (JSON-LD).
  * Карточки OpenGraph и Twitter Summary Large Image для социальных сетей.
* **Развертывание:** Статический хостинг на GitHub Pages с собственным доменом.

### 🛠️ Локальный запуск

Сайт полностью статичен и не требует сборки. Для просмотра достаточно открыть файл в браузере или поднять любой локальный сервер:

```bash
# Клонировать репозиторий
git clone https://github.com/Vancore/division.git
cd division

# Запуск через встроенный сервер Python 3
python3 -m http.server 8080

# Или с помощью Node.js
npx serve .
```

Откройте адрес `http://localhost:8080` в браузере.
